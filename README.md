# Chanda 2026

Mobile web app for the Durga Puja chanda (subscription) collection.
Data lives in the committee's Google Sheet; this site is only the front end.

- Open the site, enter the server link (first time only) and the committee PIN.
- Pick your collector name — it is saved with every payment you enter.
- Tap a name → tap an amount → **Save**.
- Printer icon → *Save as PDF* for the full register or a door-to-door due list.

Add to home screen from the browser menu to use it like an app.
